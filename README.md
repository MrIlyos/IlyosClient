# Ilyos Client

Чёрно-синее Windows-приложение для тренировок в Counter-Strike: Source v34.

## Первый этап
- WPF-интерфейс на .NET 8
- Aim Trainer с учебными мишенями
- Reaction Test
- Сборка Windows x64 через GitHub Actions

Это автономный тренировочный инструмент: он не внедряется в игру, не читает память игры и не автоматизирует наведение на игроков.

## Скачать
1. Открой вкладку **Actions**.
2. Выбери **Build Ilyos Client** и дождись завершения сборки.
3. Внизу страницы успешного запуска скачай артефакт **IlyosClient-win-x64**.
